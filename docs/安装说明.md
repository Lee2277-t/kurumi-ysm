# 安装说明（详细版）

## 一、确认环境

| 需要 | 检查方法 |
|---|---|
| Minecraft 1.20.1 | 启动器里看版本号 |
| Forge 或 Fabric | 启动器里看加载器 |
| Yes Steve Model 2.6.x | 游戏里按 Alt+Y 能开界面就是装了 |

**Forge 版和 Fabric 版不通用**，模组也一样，别下错。

## 二、装模组（已装可跳过）

1. 去 <https://modrinth.com/mod/yes-steve-model>
2. 选 **Files** → 找 §1.20.1§ + 你的加载器（forge / fabric）
3. 下下来放进 §mods§ 文件夹
4. 启动游戏，按 §Alt + Y§ 能弹出界面 = 成功

### mods 文件夹在哪

- **没开版本隔离**：§.minecraft/mods/§
- **开了版本隔离**（PCL、HMCL 常见）：§.minecraft/versions/<版本名>/mods/§

不确定的话，在启动器里点「打开版本文件夹」看。

## 三、装模型

### 方法 A：游戏内（推荐）

1. 按 §Alt + Y§ 打开模型界面
2. 点右上角的 **打开模型文件夹**
3. 把 §kurumi§ 整个文件夹拖进去
4. 回游戏输入 §/ysm model reload§

### 方法 B：手动

把 §kurumi§ 文件夹放进：

§§§
config/yes_steve_model/custom/kurumi/
§§§

目录结构要长这样：

§§§
custom/
└── kurumi/
    ├── ysm.json
    ├── models/
    ├── textures/
    └── animations/
§§§

**注意**：是 §custom/kurumi/§，不是 §custom/kurumi/kurumi/§。

## 四、选择模型

1. 按 §Alt + Y§
2. 翻页找「福贺久留美」
3. 点一下，选中
4. 关闭界面

第一次装完可能显示不出来，等 10 秒左右让模组建缓存。

## 五、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 列表里没有 | 路径不对 / 没 reload | 检查 §custom/kurumi/ysm.json§ 在不在，再 §/ysm model reload§ |
| 有名字但模型不显示 | 贴图路径错 | 确认 §textures/kurumi.png§ 存在 |
| 贴图错乱 | UV 问题 | 重新下载，别改文件 |
| 一直是原版模型 | 设置里开了「阻止渲染自身」 | 关掉它 |
| 服务器里不能用 | 模型是服主装的 | 找服主要 |
